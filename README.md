# HamidCognition Complete Ecosystem

> Historical integration-stage artifact.

The canonical integrated project is **HamidCognition-Unified**. This repository is preserved because it documents an earlier attempt to combine backend, mobile, creative-generation, dashboard, P/S/T, and market-data components.

## Components

- `backend/` — web and EUR/USD prediction lineage.
- `mobile/` — Android/on-device experiments.
- `creative-generator/` — experimental creative-function generation.
- `dashboard/` — dashboard components.
- `core/` — shared P/S/T implementation.
- `data/` — sample market data and related components.
